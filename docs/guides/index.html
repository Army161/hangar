Hangar Guides

Everything you need to install, configure, and get the most out of Hangar. Start here.

Getting Started Available

Install the Windows MSI or NSIS setup, launch Hangar, and it reads your process tree immediately. No account required, no telemetry, works fully offline.

Installation Available

Download the right installer for your platform from the releases page. Windows installers include MSI and NSIS (.exe) options. macOS and Linux support is coming soon.

Port Wall Guide Available

Every port your machine is listening on, mapped to the process and project that owns it. Click any port to open it in your browser if it serves HTTP.

Graveyard Scanner Available

Finds dormant projects ranked by what cleaning them would reclaim. Shows CPU, RAM, and disk impact so you know exactly what you're freeing up.

Safety Gates Available

Three-step safety model: Dry Run shows the impact, Typed Confirmation requires you to type the process name, Re-evaluation checks again before final action. Nothing is killed without explicit approval.

Pricing & Tiers Available

Free tier is permanent and includes full local process mapping. Plus, Pro, and Max add machines, history, sync, and fleet features as you grow.

Hangar Agent Coming Soon

Lightweight background agent for continuous monitoring and automated sweep scheduling. Documentation will be available once the agent ships.

macOS & Linux Coming Soon

Platform-specific guides for macOS and Linux installations, including known quirks and permission requirements. Coming with cross-platform release.
